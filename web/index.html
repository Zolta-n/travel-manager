Backup and migration

Import your latest full v2/v3 JSON backup to carry over entries and originals. Current-state backups can be restored through this interface. Server history exports include all revisions for archival recovery; this interface does not restore that history format. Backups include sensitive data and are not encrypted by the application.

The server retains earlier revisions and original files. Removing records does not securely erase history or older backups. Full historical data backup requires backing up the private data folder while the application is stopped. There is no historical restore/purge interface in this release.
Private is a trip label, not a separate account. Everyone with this one application password can see all trips. Store business data here only if company policy permits it.

Getting started on your NAS

  1. Install the supplied project in Synology Container Manager; follow START_HERE.md in the package. This is not installed automatically.
  2. Sign in using your dedicated Travel Manager password, not your Synology administrator password.
  3. Import your latest full v2/v3 JSON backup. It carries manual entries and original uploads forward. Imported unread documents will be processed.
  4. Drop a confirmation or choose a file/photo on your phone. Claude AI (if configured) or the NAS reader reads it, the NAS checks every date and time zone, and clear trip matches are added to the itinerary — one item per flight leg. Uncertain details remain in review, with a reason.
  5. Watch for Saved on NAS. Open the same address on another device; changes refresh when that device has no unsaved edits.
  6. For a PDF choose PDF itinerary → Open printable itinerary → Print / Save as PDF. On iPhone use Safari's print/share PDF workflow. Actual iPhone testing is still required.
  7. Download full backups regularly and back up the entire private data directory with the service stopped. Removing an item from current data does not purge server history or previous backups.
Private, not public. Use HTTPS behind the Synology reverse proxy and connect remotely over an approved VPN. Do not expose the app or DSM administration ports to the public internet. QuickConnect alone is not this custom app's hosting solution. Keep DSM, the application and its dependencies updated.
What is implemented

One-password private workspace, NAS data persistence and automatic saves, optimistic revision conflict protection, original files outside the public web root, full backup migration, editable trips/itinerary/costs, Excel exchange, selected-trip PDF printing, AI document reading with Claude (optional; needs an Anthropic API key on the NAS), date / time-zone / DST validation, an itinerary check for overlaps and nights without accommodation, and a local OCR / PDF / email fallback.

AI reading sends the original document to Anthropic. Switch it off in Documents if a file must not leave the NAS. Claude and OCR can still misread, so verify travel details.

Not provided

No live booking verification, automatic mailbox access, MSG decoding, password bypass or automatic public NAS deployment. Business and private trips share one account. There is no granular multi-user permissions model or offline edit synchronization. Test on your iPhone after each upgrade.
