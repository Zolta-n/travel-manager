# Travel Manager — notes for Claude sessions

Private travel itinerary app for one owner (Zoltan), running on a Synology DS225+ behind a Cloudflare Tunnel at `https://travel.businessintels.com`. Read `HANDOFF.md` for the NAS details and history, `UPDATE_WORKFLOW.md` for deployment.

## Hard rules
- **Merging to `main` deploys to the live NAS** (GitHub Actions → ghcr.io → Watchtower). Work on a branch; open a pull request; never push to `main` directly.
- **Never commit** `private/seed.json`, `.env`, `data/`, keys or itinerary content. `.gitignore` covers them; check `git status` before committing.
- **State format is version 2.** Any change to stored data needs a migration and must keep existing NAS data loadable. `documents[].auto` is free-form reading metadata. Trips: `type` is `Business`, `Private` or `Mixed` ("Business + private"); for `Mixed`, `privateDays` is a `|`-separated list of private dates (all other days are business). New optional columns must stay optional in Excel import.
- Keep the security posture: non-root (UID 10001), read-only root fs, `cap_drop: ALL`, port bound to `127.0.0.1` only, secure cookies, CSRF on writes, no secrets in logs.
- `install.sh` must stay POSIX `sh` (DSM BusyBox/ash). Its 16-file allowlist must match `tools/build_nas_package.py`; run that script after changing any package file so `PACKAGE.sha256` is current (CI checks it).
- The owner prefers DSM GUI steps (File Station, Task Scheduler, Container Manager) with exact copy-paste commands; no SSH.

## Layout
- `app.py` — WSGI app, route table, sessions (30-day sliding, survive restarts), per-device sign-in limits (CF-Connecting-IP behind the local tunnel), request log.
- `store.py` — SQLite revisions + content-addressed originals; `ai_results` keeps finished AI readings; `meta` holds the password fingerprint.
- `ai_reader.py` — Claude extraction (structured output) + deterministic date/zone checks; background jobs.
- `extractor.py`, `reader_worker.py` — sandboxed local PDF/OCR/email reading and photo preparation.
- `web/index.html` — single-file frontend; one sectioned script. v5 layout: views `home`, `trips`, `trip` (tabs Plan / Documents / Costs), `inbox`, `insights` (Year / Calendar / Map), `settings`; `show(view, sub)` maps the old view names (`itinerary`, `documents`, `calendar`, `countries`, …) through `VIEW_ALIAS`. Trip pictures (`tripArt`): the owner's own photo when set (`trips[].picture` = id of a document with category `Trip picture`, scaled down in the browser, loaded as a blob), else one of three stock photos in `web/scenes/` chosen by destination and served publicly by `static` (CSP allows no external images). Sync: lightweight state (`?originals=0`), three-way merge on conflict, unsaved edits kept in IndexedDB.
- `travel_log.py` — country per day (IANA zone → country via tzdata `zone.tab`; departure day = country left, arrival day = country reached) and the Excel travel log report: fills only unticked rows of the owner's workbook by editing its XML, so the map chart (chartEx), calendar and formulas survive. Never re-save that workbook with openpyxl (it drops the map chart).
- `inbound.py` — bookings by email: `POST /api/inbound` (Cloudflare Email Worker `tools/cloudflare_inbound_worker.js`, key in `X-Inbound-Secret`, only its hash in `meta`; no session/CSRF/Origin) → sender allowlist + topmost Authentication-Results check → spool in `data/inbound/` → background split in the sandboxed reader → email (without attachments) + one document per attachment (`sourceEmail`) → one Claude call per email → `ai_results`, applied by devices via `pickUpServerReadings`. Setup: `docs/BOOKINGS_BY_EMAIL.md`.
- `calendar_invites.py` — optional Outlook invites to the work email: per trip (`trips[].calendar` '' = automatic for Business/Mixed, 'on', 'off') an all-day event per run of business days + one event per flight; table `invites` tracks UID/SEQUENCE/sent hash; changes wait `SETTLE_SECONDS`; removed events get METHOD:CANCEL. The NAS never calls Cloudflare: the Worker's every-minute cron polls `GET /api/outbox` (same key as inbound) and acks with `POST /api/outbox`. Outlook replies (`text/calendar; method=REPLY`) arriving at the inbound address are ignored.
- World map: `WORLD_MAP` in `web/index.html`, generated by `tools/build_world_map.mjs`. `web/manifest.json` + icons are served publicly (home-screen icon).
- `install.sh`, `easy_data.py`, `compose.yaml` — NAS installer (pulls `ghcr.io/zolta-n/travel-manager:latest`).

## Tests
`python -m unittest discover -s tests` (installer tests use Docker/root mocks). For UI changes, also drive the page with Playwright against a local server with a fake Claude (see `tests/test_ai.py` for the fake client pattern).
